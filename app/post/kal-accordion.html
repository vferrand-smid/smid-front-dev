Photo d’identité

Quelles sont les normes pour les photos d’identité ?

Les photos d'identité française doivent respecter la norme ISO/IEC 19794-5:2005.

La taille de la photo d'identité doit être de 35x45 mm.

Liste des points principaux à respecter :

  • Ne porter aucun accessoire sur les cheveux (couvre-chefs, attaches visibles).
  • Adopter une expression neutre, bouche fermée. Pas de sourire.
  • L'ensemble du visage doit être visible (yeux, sourcils, oreilles, cou).
  • Pour les cheveux longs, les placer derrière les épaules.
  • Ne pas porter de lunettes, sauf avec une attestation médicale spécifique.

Simplifiez-vous la vie, Smartphone iD se charge de vérifier l'ensemble de ces points pour vous et vous garantit de présenter une photo d'identité valide. Plus de risque de voir sa demande rejetée par l'administration.

Avec Smartphone iD, faire une photo d'identité devient un jeu d'enfant. Plus besoin de se déplacer, faites votre photo sur votre smartphone au moment que vous convient. Nous nous occupons de mettre votre photo aux normes et vous la recevez directement dans votre boîte mail.

Où faire des photos d’identité autour de moi ?

La photo doit être faite, soit :

  • Sur une application mobile utilisant un système agréé par le ministère de l'intérieur.
  • Par un professionnel habilité, type photographe.
  • Dans une photo-cabine utilisant un système agréé par le ministère de l'intérieur.

Suivant le support choisi, les services ne sont pas identiques et le prix peut varier du simple au quadruple.

Smartphone iD est le seul à garantir que votre photo d'identité réponde aux normes exigées par l'administration et ce pour le prix le plus bas du marché.

Comment imprimer une photo en format identité ?

En utilisant Smartphone iD, vous recevez votre planche photos directement sur votre boîte mail.

Vous avez besoin d'avoir une version imprimée de votre planche ? Vous avez 3 options :

  • Demander l'impression et l'envoi de votre planche photos lors de votre commande avec Smartphone iD. Votre planche photos est imprimée par des spécialistes de l'impression photos et postée en moins de 24H.
  • Vous avez déjà passé votre commande, pas de souci. Connectez-vous avec votre email sur l'application « Photo identité officielle » de Smartphone iD. Cliquez sur le menu « Suivi de commandes » et commandez l'impression et l'envoi de votre planche photos.
  • Imprimez vous-même votre planche photos soit sur votre imprimante photo personnelle, soit sur une borne photo. Choix non préconisé pour 2 raisons :
    • Le format d'impression est différent pour chaque type d'imprimante et il peut être fastidieux de trouver celui qui convient pour obtenir les photos à la taille exigée de 35x45 mm.
    • L'administration exige une haute qualité d'impression ainsi qu'un papier photo de professionnel.

Comment faire une belle photo d’identité ?

Faire une photo d'identité où l'on se trouve beau dessus n'est pas toujours simple.

Avec Smartphone iD, faites autant de photos que vous voulez, les prises de photos sont illimitées. Ainsi vous êtes assurés d'avoir LA photo d'identité que vous désirez.

Chez un photographe, vous n'avez droit qu'à un essai.

Dans les photo-cabines, vous faites 3 essais et ensuite vous devez choisir.

Comment se coiffer pour une photo d’identité ?

Restez dans la simplicité. La photo d'identité doit être la plus naturelle possible.

Le mieux est de laisser vos cheveux détachés. S'ils sont longs, placez-les derrière les épaules pour que votre visage soit bien visible. Vous pouvez choisir de vous attachez les cheveux mais dans ce cas, aucune attache ne doit être visible et la coiffure ne doit pas être trop sophistiquée.

Si vous avez une frange, attention à ce qu'elle ne recouvre pas vos sourcils, sinon vous risquez un refus de l'administration.

Peut-on se maquiller pour une photo d’identité ?

Oui, vous pouvez être maquillé sur votre photo d'identité. Par contre, le maquillage doit être léger. Ne mettez pas de couleur trop prononcée sur vos yeux ou vos lèvres. La photo d'identité doit être la plus naturelle possible.

Peut-on mettre des boucles d’oreilles pour photo d’identité ?

Oui, vous pouvez porter des boucles d'oreilles sur votre photo d'identité, si elles sont discrètes. Les boucles d'oreilles trop voyantes ou trop volumineuses seront refusées par l'administration.

Peut-on garder ses lunettes pour une photo d’identité ?

Non, nous vous déconseillons de porter vos lunettes sur votre photo d'identité. L'administration accepte très peu de photos avec lunettes car les critères demandés sont très stricts.

Seules les personnes disposant d'une attestation médicale les obligeant à porter leurs lunettes sur leur photo d'identité sont autorisées. Et dans ce cas, elles doivent respecter les règles suivantes :

  • ne pas avoir de monture épaisse.
  • les yeux et les sourcils ne doivent pas être cachés par la monture.
  • Il ne doit pas y avoir le moindre reflet sur les verres.
  • Les verres teintés ou colorés sont interdits.

Code ePhoto

Comment obtenir un code ePhoto ?

Vous devez fournir un code photo signature numérique (ou code ePhoto) pour une demande en ligne sur le site de l'ANTS ?

C'est très simple, allez sur le site Smartphone-iD : Application Photo Identité et ephoto, choisissez le document dont vous avez besoin (Permis de conduire, Titre de séjour, DCEM, ...). Ensuite faites votre photo et votre signature sur votre smartphone et c'est fini. Après validation de votre photo par notre équipe d'experts, vous recevrez votre code ePhoto dans votre boîte mails en quelques minutes.

Où trouver le code ePhoto ?

Le code ePhoto est écrit sur la planche photos qui est disponible :

  • sur l'application « Photo identité officielle » de Smartphone iD, menu « Suivi de commandes »
  • directement dans le mail que vous avez reçu. Sur ce mail, le code ePhoto est également indiqué.

Comment entrer le code ePhoto ?

Vous avez 2 possibilités :

  • Soit vous recopiez le code ePhoto de 22 caractères (lettres et chiffres) qui figure sur votre planche photos. Attention à bien écrire les lettres en majuscule et à ne pas mettre d'espace :)
  • Soit vous faites un copier-coller du code ePhoto indiqué dans le mail que vous avez reçu.

Combien de fois peut-on utiliser le code ePhoto ?

Le code ePhoto est à usage unique. Une fois que vous l'avez saisi sur le site de l'ANTS, vous ne pourrez plus l'utiliser.

L'ANTS sécurise vos données en empêchant la multiplication des utilisations de codes ePhoto.

Combien de temps est conservé le code ePhoto ?

Le code ePhoto est valable pendant 6 mois. Cela correspond au délai de validité de votre photo d'identité.

Vous avez 6 mois pour l'utiliser, ensuite il ne fonctionnera plus.

Sur une planche photos combien y-a-t-il de code ePhoto ?

Sur une planche photos, vous avez UN code ePhoto.

Si vous avez besoin d'un autre code ePhoto, vous pouvez l'obtenir sans refaire vos photo et signature et ce pendant 6 mois. Pour cela, allez dans le menu « Suivi de commandes » de l'application « Photo identité officielle » de Smartphone iD, sélectionnez votre commande puis demandez un nouveau code ePhoto. Vous le recevrez en quelques minutes.

Pourquoi mon code ePhoto ne fonctionne-t-il pas ?

Plusieurs raisons sont possibles :

  • Vous avez fait une erreur lors de la saisie de votre code ePhoto. Les lettres doivent être en majuscule, il faut saisir les 22 caractères sans mettre d'espace, vous avez confondu les lettres O avec les chiffres 0.
  • Vous avez déjà utilisé ce code ePhoto. Le code ePhoto étant à usage unique, demandez un nouveau code ePhoto directement dans l'application « Photo identité officielle » de Smartphone iD.

Votre commande date de moins de 6 mois, c'est simple, pas besoin de refaire vos photo et signature. Allez dans le menu « Suivi de commandes », sélectionnez votre commande puis demandez un nouveau code ePhoto.

Votre commande date de plus de 6 mois, dans ce cas, passez une nouvelle commande et recevez le code ePhoto en quelques minutes.

Comment entrer le code ePhoto pour le permis ?

C'est très simple, allez sur le site de l'ANTS Permis de conduire - Accueil (ants.gouv.fr), choisissez le motif de votre demande (demande d'inscription à l'examen du permis de conduire, demande de fabrication de votre permis de conduire, …) puis remplissez le formulaire affiché. Dans la case « code photo signature numérique », saisissez votre code ePhoto, et voilà !
